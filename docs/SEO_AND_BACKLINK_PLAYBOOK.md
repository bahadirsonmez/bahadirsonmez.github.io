## High-value actions

1. Add the portfolio URL to the GitHub profile and LinkedIn contact section.
2. Add each canonical app-site URL to its GitHub repository description and README.
3. Use each app subdomain as its Marketing URL in App Store Connect; use the canonical legal page as its Privacy Policy URL.
4. Submit the root domain property and all five sitemaps in Google Search Console.
5. Share useful build notes, release retrospectives, or technical explanations that naturally link to the relevant app page.
6. Seek editorial listings only when the app is a strong fit; personalize every pitch and identify the useful angle for that audience.

## Quality rules

- Prefer descriptive links such as “iKeep private notes app” over “click here.”
- Keep names, descriptions, developer identity, and URLs consistent across profiles.
- Never exchange, automate, or purchase links.
- Avoid posting the same promotional text across unrelated communities.
- Answer a real question or provide a useful story before linking.
- Track referring domains and search queries in Search Console monthly; expand pages only where real demand appears.

## Monthly review

- Check indexed pages, crawl issues, Core Web Vitals, impressions, clicks, and branded versus non-branded queries.
- Record legitimate new links and remove or disavow nothing unless there is clear evidence of a manual-action risk.
- Refresh app-page copy when the product changes; do not change titles merely to chase short-lived rankings.
